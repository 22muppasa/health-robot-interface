# Voice Assistant Quick Start Guide

## Enabling the Voice Assistant

1. Look at the **Voice Assistant** panel in the dashboard
2. Toggle the **"Enabled"** switch to turn on the assistant
3. You'll see a "Listening for 'Claire'..." indicator when ready

## Using Push-to-Talk

1. Press and **hold** the large circular **"Hold to Talk"** button
2. Speak your command clearly:
   - "Check my vitals"
   - "Call the nurse"
   - "Join the meeting"
   - "Navigate to room 101"
3. **Release** the button when done speaking
4. Wait for the assistant to respond

## Using Wake Word (Always-Listening Mode)

1. Ensure the Voice Assistant is **Enabled**
2. Say **"Claire"** to activate
3. Follow immediately with your command:
   - "Claire, check my vitals"
   - "Claire, call the nurse"
   - "Claire, what's my temperature?"

The assistant will respond with spoken audio!

## Understanding the Visual Indicators

| Indicator | Meaning |
|-----------|---------|
| 🔴 Blue pulse | Wake word detection is active |
| 📍 Red dot + pulse | Recording (during push-to-talk) |
| 🎤 Pulse animation | Processing command |
| 🔊 Green section | Assistant is speaking |

## Troubleshooting

### "Browser Not Supported"
- You're using a browser that doesn't support Web Speech API
- Try: Chrome, Firefox, Edge, or Safari (latest versions)

### Not hearing audio responses
- Check your browser's audio settings
- Ensure speaker volume is not muted
- Check browser tab audio is not muted
- Refresh the page

### Wake word not being detected
- Speak clearly "Claire" at the beginning
- Make sure microphone has permission
- Restart the assistant by toggling off/on
- Ensure background noise isn't excessive

### Commands not being processed
- Enable the Voice Assistant first
- Try using Push-to-Talk instead of wake word
- Check if OPENAI_API_KEY environment variable is set
- Verify backend is running

## Microphone Permissions

When you first use the voice features, your browser will ask for microphone access:
- **Allow** - Required for voice features to work
- **Block** - Voice features will not work
- To re-enable: Check browser settings or click the microphone icon in address bar

## Privacy Notes

- Your voice is captured by the browser
- Transcription happens on your browser (Web Speech API) or backend
- Responses are generated by OpenAI API
- Audio is not stored or logged on the device

## Tips for Best Results

✅ **Do:**
- Speak clearly and naturally
- Use complete sentences
- Position microphone 6-8 inches away
- Wait for assistant to finish speaking before speaking again

❌ **Don't:**
- Speak too quietly or too loudly
- Interrupt the assistant while it's speaking
- Use background music/TV while speaking
- Hold the button while there's loud background noise

## Advanced Features

### Custom Wake Word
- Currently set to "Claire"
- To change: Edit `src/hooks/useWakeWordDetection.ts`
- Look for line: `wakeWord: 'claire'`

### Voice Tone
- TTS voice set to "alloy"
- To change: Edit `backend/voice_service.py`
- Look for line: `voice="alloy"`
- Options: alloy, echo, fable, onyx, nova, shimmer
